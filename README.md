## Selected projects

### [Smart Pest Monitoring System](https://github.com/Aloysiouskyle/smart-pest-monitoring-system#readme)

My final-year project explores how computer vision could help smallholder farmers in Uganda detect maize pests. The Python prototype uses YOLOv8 and a Streamlit dashboard. It uses simulated environmental readings and previews farmer advice in English and draft Luganda. Field validation is still planned.

### [Python E-Voting System](https://github.com/Aloysiouskyle/E-voting-system-refined#readme)

My coursework team built a voting program that runs in the terminal. I wrote `models.py`, where I defined the data models and handled saving and loading data with JSON.
